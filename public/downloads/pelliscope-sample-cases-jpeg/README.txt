PELLISCOPE SAMPLE CASE IMAGES — JPEG-COMPATIBLE COPY
====================================================

This separate package contains JPEG-compatible copies of the nine public
demonstration photographs used by the PelliScope clinic presentation.

The original mixed-format package remains unchanged.

Cases 01, 03 and 04 were copied from their existing JPEG/JPG source files
without modification. The three Case 02 photographs were available in the
website repository only as WebP files and were converted to high-quality JPEG
copies at their original 640 x 853 pixel dimensions.
